#  Heka (هيكا): Ancient Egyptian Hieroglyphics Translation & AR App

![Flutter](https://img.shields.io/badge/Flutter-3.x-blue) ![Firebase](https://img.shields.io/badge/Firebase-Auth%20%26%20Firestore-orange) ![AI](https://img.shields.io/badge/AI-ConvNeXt%20%7C%20SAM%20%7C%20BART%20%7C%20BERT-green)

Heka is a cross-platform application for **ancient Egyptian hieroglyph detection, AI-powered translation, and Augmented Reality (AR) exploration**.

 **1st Place, 2nd Scientific Summit Forum for Sustainable Innovation (AI & Cybersecurity)**
 Graduation Project (Grade: A+), Faculty of Computers and Information, Ain Shams University

##  Tech Stack

| Area | Technologies |
|---|---|
| **Mobile / Web App** | Flutter |
| **Backend & Auth** | Firebase (Authentication, Firestore) |
| **AI Models** | ConvNeXt, SAM, BART, BERT |
| **Languages** | Dart, Python (Jupyter Notebooks) |
